# ShadowBooks — تطبيق أندرويد

مشروع Android أصلي بلغة Kotlin وواجهات Jetpack Compose، لطلاب الصف الثالث الثانوي (المنهج اليمني).

## ما يتضمنه المشروع

- [تصميم شاشة الترحيب المعتمد](design/welcome-design-yemen.png) بشعار الجمهورية اليمنية وأيقونة الكتاب المضيئة، وعنوان «منهج الصف الثالث الثانوي» وإهداء دفعة 2027. ينقلك زر «دخول» إلى المكتبة، ويمكن تمرير الشاشة عند تكبير الخط أو في الوضع الأفقي.
- مصدر الشعار داخل لوحة الترحيب: [Emblem of Yemen (2) — Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Emblem_of_Yemen_(2).svg) (ملك عام). خط [Tajawal](https://github.com/google/fonts/tree/main/ofl/tajawal) مضمّن للعمل دون إنترنت، مع [رخصته](app/src/shared/assets/licenses/Tajawal-OFL.txt).
- [تصميم المكتبة المعتمد](design/library-books-chat.jpg): ثلاثة عشر غلافًا على خمسة رفوف خشبية من اليمين إلى اليسار، والإنجليزية في وسط الرف الأخير. كل غلاف زر مستقل يفتح الكتاب أو يتيح اختيار الجزء. أغلفة WebP مضمّنة للعمل دون اتصال، ويُحفظ موضع الرف عند الرجوع من القراءة.
- شاشة اختيار جزأي الحديث ونسختي الإنجليزية (كتاب الطالب وكتاب الواجب)، مع بقاء عدد أغطية المواد 13.
- [تصميم قارئ الكتب المعتمد](design/pdf-reader-final-rtl.png): يعرض صفحات PDF الفعلية على خلفية بيضاء من دون قصّ أو شريط ثابت. اسحب للأعلى أو للأسفل للتصفّح، أو اكتب رقم الصفحة واضغط «انتقال» من لوحة المفاتيح أو علامة الصح. تُقبل الأرقام العربية والفارسية واللاتينية.
- «التالي» أسفل اليمين بين (+) و(−)، و«السابق» أسفل اليسار. كبّر أو صغّر بإصبعين أو بالزرّين، واسحب أفقيًا لقراءة أطراف الصفحة المكبّرة.
- قائمة أعلى اليسار: **القراءة الليلية**، **تخطيط Casio Business**، **عرض الصفحة** (الصفحة كاملة أو ملاءمة العرض)، **علامات القراءة** (حفظ باسم وفتح وحذف، لكل كتاب أو جزء على حدة)، و**وضع التركيز**. المس الصفحة مرة واحدة لاستعادة الأزرار.
- الحاسبة تعمل **داخل القارئ ودون اتصال**: يبقى الكتاب وشريط صفحاته في الأعلى وتظهر الأزرار أسفله. اسحب الفاصل لتغيير النسبة، أو اطوِ اللوحة بزر الرجوع أو «طيّ الحاسبة». يبقى الإدخال أثناء تقليب الصفحات والطيّ وتغيير اتجاه الشاشة.
- **حاسبة مستقلة بتخطيط Casio Business**: لا يُضمَّن التطبيق الخارجي ولا كوده أو صور أزراره. [لوحة المفاتيح](design/calculator-first-panel.png) تُظهر الوظائف الصفراء (`SHIFT`) والحمراء (`ALPHA`) فوق أزرارها مباشرة؛ منها `∑` و`∏` فوق `Logₐx` و`mod` و`÷R` فوق الكسر. يفتح `2nd` الدوال، ومنها `int(X²,0,1)` و`diff(X²,3)` و`solve(X²−2,1)`. ومن `MODE` اختر الأعداد المركّبة، المعادلات والأنظمة، المصفوفات، المتجهات، الإحصاء والانحدار والتوزيعات، الجداول والرسم، الكسور الدقيقة، تحويل الوحدات أو الثوابت. تظهر المدخلات والنتائج مكان الأزرار **تحت نفس الصفحة**، ويعيد زر «لوحة الأزرار» الإدخال السابق. [دليل الأوضاع والأمثلة، ومقارنة التغطية بالمصادر والحدود](docs/calculator-ar.md).
- أيقونة ShadowBooks مضافة إلى موارد التطبيق.
- سكربت يتحقق من وجود ملفات PDF الخمسة عشر وينزّلها إلى أصول التطبيق قبل البناء؛ لذلك يتضمن APK الناتج جميع الكتب للعمل دون اتصال.

## نسخة التجربة الخفيفة (بلا كتب المنهج)

نسخة `trial` تبقي المكتبة والمواد والأجزاء والقارئ كاملة. تفتح كل مادة **نفس ملف PDF التجريبي من خمس صفحات**، وتظل علامات القراءة مستقلة لكل جزء. لا تُضمَّن كتب المنهج ولو كانت موجودة على جهاز البناء. تظهر النسخة باسم «ShadowBooks تجريبي» وتُثبّت بمعرّف منفصل `com.shadowbooks.trial`، فلا تستبدل النسخة العادية.

للتجربة محليًا باستخدام JDK 17 وAndroid SDK 35، **لا تُشغّل سكربت تنزيل الكتب**:

```bash
bash ./gradlew :app:testTrialUnitTest :app:assembleTrial
python3 scripts/verify_trial_apk.py app/build/outputs/apk/trial/app-trial.apk
```

في سير البناء اليدوي اختر `trial` (الافتراضي) وعلى الفرع المطلوب. ويمكن طلب البناء الخفيف بدفعة إلى فرع التجربة `arena/b4e6cf40-shadowbooks` تحمل الرسالة `[trial-apk]`؛ الدفعات العادية لهذا الفرع لا تبني أي APK. يفحص السير محتوى APK وتوقيعه ثم يحفظ `ShadowBooks-Trial.apk` في Artifact باسم `ShadowBooks-Trial-APK`. يحتاج الهاتف إلى هذا الملف فقط؛ لا تُنزَّل كتب عند فتحه. النسخة موقّعة بمفتاح اختبار وليست إصدار المتجر. عند الجاهزية للنسخة الكاملة، اختر `full`: لا يلزم حذف العيّنة أو إعادة تعديل التطبيق؛ تدخل العيّنة في `trial` فقط.

## تشغيل النسخة الكاملة وبناؤها محلياً

1. افتح مجلد `ShadowBooksAndroid` في Android Studio واستخدم JDK 17.
2. نزّل الكتب إلى مجلد أصول التطبيق:

```bash
bash scripts/download_books.sh
```

3. ابنِ التطبيق بعد تثبيت Android SDK 35:

```bash
chmod +x ./gradlew
./gradlew assembleDebug
```

ملفات PDF مستثناة من مستودع Git لتجنّب رفع نحو 400 MB من الملفات الثنائية. عند البناء محلياً شغّل السكربت أعلاه، وفي GitHub Actions يتم تشغيله تلقائياً قبل بناء النسخة الكاملة فقط؛ بعدها تُضمّن الكتب كلها في APK. يتطلب ذلك أن تكون روابط Google Drive متاحة للتنزيل.

## البناء على GitHub

يوجد Workflow في `.github/workflows/build-android.yml`. بعد رفع المصدر إلى فرع `main`، ينزّل الكتب، يبني APK تجريبياً، ثم يحفظه كـ Artifact باسم `ShadowBooks-debug-apk` في صفحة Actions.

مخرجات التجربة والتصحيح مخصّصة للتثبيت للاختبار، وليست إصدارًا موقّعًا للنشر في المتجر.
